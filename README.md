# Lantern Shoals privacy policy

Public privacy policy and support contact for Lantern Shoals, published by Graham Luxford.

Live URL: https://glux52495.github.io/lantern-shoals-privacy/

Last updated: 4 October 2026.

This repository contains only the static public policy website. It contains no game source, assets, player data or credentials. No JavaScript, analytics, cookies or external fonts are added by the site. GitHub Pages supplies hosting and security logging.

Publishing: GitHub Pages, `main` branch, repository root. Edit `index.html` and `styles.css`, update the policy date when practices change, and push to `main`. No build tools or paid services are required.

Contact: https://github.com/Glux52495/lantern-shoals-privacy/issues — issues are public; do not post sensitive information.
